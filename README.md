# Akshay Kunchalapalli — Portfolio

Responsive professional portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

```bash
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000.

## Deploy

Publish the `dist` directory with any static host. No build command or dependencies are required.

## Content

- Six featured projects with case-study dialogs
- Project category filters
- Earlier project archive
- Technical skills and professional experience
- Email and GitHub contact links

Edit `dist/app.js` to update projects and `dist/index.html` to update styling and profile content. Project previews are illustrative interface concepts.
